USBeaver

The USBeaver is a sneaky little Raspberry Pi Pico loaded up with Human Input Device (HID) code to carry out automated actions on the host machine. This project was designed around a talk for DAMSEC security club at OSU to teach students about physical access attacks and payload scripting.
